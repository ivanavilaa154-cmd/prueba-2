# Plantillas de fuente

Copiar esta carpeta a `sources/<tenant_slug>/<source_id>/` y completar.
1. `source.yml`: cómo leer (arquetipo, autenticación, streams).
2. `cerebro fuente descubrir` para obtener muestra y esquema inferido.
3. `mapping.yml`: cómo traducir al modelo canónico (se puede partir de la propuesta del asistente de mapeo, docs/05 §9).
4. `cerebro mapping validar` → vista previa → aprobación → `cerebro mapping publicar`.
