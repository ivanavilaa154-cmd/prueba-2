Odoo

Sin configurar

Conexión de solo lectura por la API de Odoo (12 o superior, en la nube o en tu servidor). Conviene un usuario propio para la integración con permisos de Ventas, Facturación e Inventario (solo lectura alcanza). La API key se crea en Odoo: tu usuario → Preferencias → Seguridad de la cuenta → Nueva clave API.

Archivos CSV o Excel

Un archivo por tabla, con el nombre de la tabla (clientes.xlsx, ventas.csv…). Se aceptan 1.234,56, fechas dd/mm/aaaa y separador ;. El mínimo para empezar es clientes. Las columnas que falten quedan vacías.

Base de datos del ERP

Para ERPs sin API (Tango, Bejerman, SAP Business One sobre SQL Server, sistemas propios) la plataforma se conecta directo a la base con un usuario de solo lectura. Se configura en backend/.env y se reinicia el servidor:

ERP_URL=mssql+pyodbc://lector:clave@servidor/TANGO?driver=ODBC+Driver+18+for+SQL+Server

Después hay que adaptar config/diccionario_datos.yaml y los filtros de config/roles.yaml a las tablas de ese ERP.

Probá los permisos con tus datos

La consulta pasa por las mismas barreras que usa el chat: solo lectura, tablas del rol y cartera del vendedor. Cambiá el usuario arriba y compará. Esto no necesita clave de API.
